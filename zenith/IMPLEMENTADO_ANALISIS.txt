1. [Decompiler] Global Script Search (getXrefIndex + Dec.globalSearch)
   - Cachea imports y strings por bytecode unico (xrefCache).
   - Busca en todos los scripts visibles tras filtros y filtra Script List.
2. [RSpy -> Decompiler] Remote XRefs (Zenith.findScriptXRefs + boton "Find Script XRefs")
   - Salta a la pestana Decompiler, rellena Global Search con el nombre del remote y busca sus referencias en scripts.
3. [Decompiler] GC Closure Search (Dec.gcSearch)
   - Escanea closures Lua vivas via getgc(false), debug.info, getconstants y getupvalues sin congelar el cliente.
4. [Decompiler] Export Place .rbxmx (exportPlaceRbxmx)
   - Serializa Workspace, ReplicatedStorage, Lighting, StarterGui, StarterPack y StarterPlayer en formato XML .rbxmx, incluyendo scripts decompilados y ValueBases.
5. [RSpy] Group By Remote + Replay Custom Args
   - Agrupa llamadas repetidas por remote/direccion/metodo con contador (xN) manteniendo seleccion de la ultima llamada.
   - Evalua expresiones Lua separadas por coma en "Custom Args" con loadstring/load bajo pcall y reenvia en hilo interno sin auto-logueo.
6. [RSpy] Stealth Hook (oth.hook / oth.unhook) + Interaction Spy (ProximityPrompt / ClickDetector)
   - Usa oth.hook cuando "Prefer Stealth Hook (oth)" esta activo (y oth.unhook al descargar).
   - Captura ProximityPromptService.PromptTriggered y ClickDetector.MouseClick cuando "Log Interactions" esta activo, con filtro "Interactions" y Repeat Call via fireproximityprompt / fireclickdetector.
