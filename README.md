# ARandomMenu
Just a Normal Random Menu Nothing else.

## Source layout

```text
src/
├── Supported/
│   ├── MM2.luau
│   └── TRS.luau
├── gui/
│   └── Current/
│       └── ARandomMenu.luau
├── library/
│   ├── AssetRegistry.luau
│   └── ProfileRegistry.luau
├── assets/
│   ├── images/
│   └── manifest.json
└── Profile/
    ├── index.json
    ├── mm2.json
    └── trs.json
```

`Supported` contains the game modules enabled by default. Images belong in
`src/assets/images`, while `src/gui/Current` contains the active interface.
