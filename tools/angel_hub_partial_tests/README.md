# Angel Hub: pruebas parciales

Estas pruebas simulan objetos Roblox: no comprueban comportamiento real en Roblox, la aceptación del servidor ni la compatibilidad con ejecutores. Incluyen arranque PC/móvil y fuera de MM2, Speed, Rise, X-Ray, Anti AFK, Get Gun por touch, restauración y bloqueo de módulos pendientes.

```sh
npm install --prefix /tmp/angel-test-deps @luau-rs/luau@0.739.0
node tools/angel_hub_partial_tests/run.cjs
```
